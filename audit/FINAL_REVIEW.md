## 结论

当前主张应保持为：可信控制器下，已验证行为证据驱动延迟裁决期间的权限限制与条件恢复。新版 B3/B4 功能验证及 Linux DAC 真实操作记录支持这个限定主张。历史模型、内核采集、通信和微基准是各自独立的组件证据。

这次发现并不意味着实验没有真实运行。尤其是跨节点 30 轮原始终端输出已找回，数值与 JSON 完全一致；问题是测量边界和随后写入论文的解释超过了代码实际验证的内容。

## 统计与实验表修正

1. 数据集实际为 240：60 确定违规、60 合规、60 多步违规、60 无标签模糊样本。180 例有标签输入并不包含那 60 个 null 样本。标签来自模板生成代码；撤下没有记录支撑的“两位标注者+第三人仲裁”、120+60 数据拆分及事后功效充分性结论。
2. 多数错误 6/180、27/180、4/180 均由逐例票重算确认；谱相关数值亦吻合。历史 FPR/FNR 字段实际上使用总数 N 为分母，正文表改称 FP/N、FN/N；AgentHarm 的 FPR/FNR 则保持类别分母。
3. GLM 与异构多数的不一致对为 b=c=2，连续性校正截断至零后 p=1.000；原 .617 来自不截断的公式。修复 `rq2/single_juror_stats.py` 及 artifact 副本，历史 JSON 不覆盖。其他表内 p 值及 Clopper–Pearson 区间重算吻合；说明探索性双侧检验且未多重校正。
4. AgentHarm：GLM 64/351，缺失一条良性响应；其余模型及多数均为 352。缺失时有效票投票、平票良性，已披露。
5. 模糊样本 29.5% 是参数 Monte Carlo 输出，不是 60 个真实模型投票的 bootstrap。保留为模型示例，删除经验 CI 和保护假共识的结论。
6. 共谋检测 100 合成对重新调用评分逻辑，结果与保存文件一致：precision .4167→1.0000，recall 均 .3333。旧 .57/.88 撤下。
7. 双观测的 LSM99% 是独立随机覆盖假设，不是真实 LSM 流；检测率及 CI 端点按结果文件纠正。只有汇总，没有每次重复数组，因此未声称独立重建 CI。
8. 微基准 HMAC 只是摘要计算；Ed25519 行计时包含随机消息生成和无效签名异常路径；signer 不含上游 MAC/下游验证。保存分位数与表一致，但不是新版完整验证器延迟。
9. 并发测试实际是每线程 500 个事件的饱和短跑，不是每 Agent 50 events/s；补入 50 线程 P99=71.3862 ms，不能从总吞吐推已验证 Agent 容量。
10. 旧状态消融 38→19、占比 .6333→.82 对应 fluctuating 配置，数值吻合；仍标为被新版语义替代的历史模拟。
